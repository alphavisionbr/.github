# Contribuindo com a Alphavision®

Obrigado pelo interesse em contribuir com os projetos open source da Alphavision®.

Acreditamos que o compartilhamento de conhecimento, ferramentas e experiências contribui para uma comunidade de tecnologia mais aberta, acessível e colaborativa.

Este documento apresenta algumas orientações gerais para contribuições aos nossos projetos.

> English version: [CONTRIBUTING.en.md](CONTRIBUTING.en.md)

## Como contribuir

Dependendo do projeto, você pode contribuir de diferentes maneiras:

- Reportando bugs e comportamentos inesperados
- Sugerindo melhorias e novos recursos
- Corrigindo problemas existentes
- Melhorando documentação
- Enviando traduções e revisões
- Compartilhando exemplos de utilização
- Enviando código por meio de Pull Requests

Antes de contribuir, consulte o README e as orientações específicas do repositório, quando disponíveis.

## Issues

Antes de abrir uma nova Issue:

1. Verifique se já existe uma Issue relacionada ao mesmo assunto.
2. Utilize um título claro e objetivo.
3. Descreva o problema ou sugestão com o máximo de contexto possível.
4. Informe versões, ambiente e outros dados técnicos relevantes quando aplicável.
5. Inclua passos para reprodução quando estiver relatando um problema.

Evite incluir senhas, credenciais, tokens, chaves de API ou qualquer outra informação confidencial.

Problemas relacionados à segurança não devem ser publicados em Issues públicas. Consulte nossa [Política de Segurança](SECURITY.md).

## Pull Requests

Pull Requests são bem-vindos.

Sempre que possível:

- Mantenha cada Pull Request focado em uma única alteração ou objetivo.
- Explique claramente o que foi alterado e por quê.
- Relacione a Pull Request a uma Issue existente quando aplicável.
- Preserve os padrões de código e a estrutura existentes no projeto.
- Atualize a documentação quando a alteração modificar funcionalidades ou comportamento.
- Teste suas alterações antes do envio.

Projetos específicos poderão possuir orientações adicionais para desenvolvimento e contribuição.

## Idiomas

A documentação dos projetos da Alphavision® será produzida prioritariamente em Português do Brasil (pt-BR).

Sempre que possível, também disponibilizaremos documentação em English (en) para a comunidade internacional.

Contribuições relacionadas a traduções e melhorias de documentação são bem-vindas.

## Licenciamento

Cada projeto poderá possuir sua própria licença.

Ao contribuir com um projeto da Alphavision®, você concorda que sua contribuição poderá ser distribuída de acordo com a licença definida naquele repositório.

Consulte sempre o arquivo `LICENSE` do projeto antes de enviar uma contribuição.

## Código de Conduta

Esperamos que todas as interações nos projetos da Alphavision® sejam profissionais, respeitosas e colaborativas.

Orientações mais detalhadas poderão ser estabelecidas em nosso Código de Conduta.

## Segurança

Se você identificar uma possível vulnerabilidade de segurança, não publique os detalhes em uma Issue pública.

Consulte nossa [Política de Segurança](SECURITY.md) para saber como comunicar o problema de forma responsável.
