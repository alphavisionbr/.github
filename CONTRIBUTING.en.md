# Contributing to Alphavision®

Thank you for your interest in contributing to Alphavision® open source projects.

We believe that sharing knowledge, tools, and experience contributes to a more open, accessible, and collaborative technology community.

This document provides general guidelines for contributing to our projects.

> Versão em Português: [CONTRIBUTING.md](CONTRIBUTING.md)

## How to contribute

Depending on the project, you can contribute in different ways:

- Reporting bugs and unexpected behavior
- Suggesting improvements and new features
- Fixing existing issues
- Improving documentation
- Submitting translations and revisions
- Sharing usage examples
- Contributing code through Pull Requests

Before contributing, please review the repository's README and any project-specific guidelines, when available.

## Issues

Before opening a new Issue:

1. Check whether an Issue already exists for the same topic.
2. Use a clear and descriptive title.
3. Describe the problem or suggestion with as much relevant context as possible.
4. Include versions, environment details, and other relevant technical information when applicable.
5. Include reproduction steps when reporting a problem.

Do not include passwords, credentials, tokens, API keys, or any other confidential information.

Security-related issues should not be published in public Issues. Please refer to our [Security Policy](SECURITY.en.md).

## Pull Requests

Pull Requests are welcome.

Whenever possible:

- Keep each Pull Request focused on a single change or objective.
- Clearly explain what was changed and why.
- Link the Pull Request to an existing Issue when applicable.
- Follow the existing code standards and project structure.
- Update the documentation when your changes affect functionality or behavior.
- Test your changes before submitting them.

Specific projects may provide additional development and contribution guidelines.

## Languages

Documentation for Alphavision® projects will primarily be produced in Brazilian Portuguese (pt-BR).

Whenever possible, we will also provide documentation in English (en) for the international community.

Contributions involving translations and documentation improvements are welcome.

## Licensing

Each project may have its own license.

By contributing to an Alphavision® project, you agree that your contribution may be distributed under the license defined in that repository.

Always review the project's `LICENSE` file before submitting a contribution.

## Code of Conduct

We expect all interactions within Alphavision® projects to be professional, respectful, and collaborative.

More detailed guidelines may be established in our Code of Conduct.

## Security

If you identify a potential security vulnerability, do not publish the details in a public Issue.

Please refer to our [Security Policy](SECURITY.en.md) for information on how to report the issue responsibly.
