## Checklist

Antes de enviar esta Pull Request, confirme:

- [ ] Revisei minhas próprias alterações.
- [ ] Mantive o padrão de código e a estrutura existente no projeto.
- [ ] Testei as alterações realizadas.
- [ ] Atualizei a documentação quando necessário.
- [ ] Não incluí senhas, credenciais, tokens, chaves de API ou outras informações confidenciais.
- [ ] Minha contribuição está de acordo com as diretrizes do arquivo `CONTRIBUTING.md`.
- [ ] Minha contribuição respeita o `CODE_OF_CONDUCT.md`.
